How the embedded model is bypassed:
  The Emscripten data-package loader calls Module["getPreloadedPackage"] before
  fetching the .data. The worker sets getPreloadedPackage to return an empty
  ArrayBuffer, so no .data is fetched. The loader then writes empty placeholder
  files (/encoder.onnx, /decoder.onnx, /joiner.onnx, /tokens.txt) which are
  never referenced. The worker writes the real int8 model to /stt-*.onnx and
  points the recognizer config at those paths.
